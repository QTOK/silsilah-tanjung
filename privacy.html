Kebijakan Privasi

Berlaku sejak: 18 April 2026

1. Pendahuluan

Aplikasi "Silsilah Suku Tanjung" menghormati privasi pengguna. Kebijakan ini menjelaskan bagaimana kami mengelola informasi terkait penggunaan aplikasi. Dengan menggunakan aplikasi ini, Anda menyetujui ketentuan yang tercantum di sini.

2. Pengumpulan Data

⚠️ APLIKASI INI TIDAK MENGUMPULKAN, MENYIMPAN, ATAU MEMBAGIKAN DATA PRIBADI APAPUN DARI PENGGUNA.

Kami tidak meminta:

  • Nama, email, nomor telepon, atau identitas pribadi
  • Lokasi GPS, kontak, galeri, atau mikrofon
  • Data analitik, iklan, atau pelacakan perilaku

Semua informasi silsilah bersifat statis dan telah tertanam langsung dalam kode aplikasi saat pengembangan.

3. Penyimpanan & Fungsi Offline

Aplikasi ini menggunakan teknologi Progressive Web App (PWA) dan Service Worker untuk menyimpan file aplikasi (HTML, CSS, JS, gambar, musik) secara lokal di perangkat Anda. Cache ini hanya berfungsi untuk:

  • Memungkinkan akses offline tanpa koneksi internet
  • Mempercepat waktu muat halaman

Cache tidak berisi data pribadi dan dapat dihapus kapan saja melalui pengaturan browser/perangkat Anda.

4. Cookie & Teknologi Pelacakan

Kami tidak menggunakan cookie, pixel pelacak, fingerprinting, atau alat analitik pihak ketiga (seperti Google Analytics, Firebase, dll.) untuk memantau aktivitas pengguna.

5. Izin Perangkat

Aplikasi ini tidak meminta izin akses apa pun dari sistem operasi Android/iOS. Tidak ada akses ke kamera, mikrofon, penyimpanan, lokasi, atau jaringan selain koneksi internet awal untuk memuat halaman.

6. Privasi Anak

Aplikasi ini aman untuk semua usia. Karena tidak ada pengumpulan data, login, atau konten interaktif pihak ketiga, aplikasi ini tidak berisiko terhadap privasi anak di bawah 13 tahun.

7. Perubahan Kebijakan

Kami berhak memperbarui kebijakan ini sewaktu-waktu. Perubahan akan efektif segera setelah dipublikasikan di halaman ini. Kami menyarankan pengguna untuk memeriksa halaman ini secara berkala.
